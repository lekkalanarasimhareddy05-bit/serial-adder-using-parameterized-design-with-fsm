# Parameterized Serial Binary Adder Using Finite State Machine (FSM)

## Overview

This project implements a **Parameterized Serial Binary Adder** in **Verilog HDL** using a **Finite State Machine (FSM)**. The design performs binary addition serially by processing one bit during each clock cycle. The architecture consists of parameterized shift registers, a full adder, a carry flip-flop, a counter, and an FSM controller.

The design is parameterized, allowing different operand widths by changing the parameter value (`N`) without modifying the overall architecture. The project was designed, simulated, and verified using **Xilinx Vivado**.

# Project Architecture

The design is divided into the following modules.

## FSM Controller (`fsm_controller`)

The FSM controls the complete serial addition process.

### States

- IDLE
- LOAD
- ADD
- DONE

### Functions

- Waits for the Start signal
- Loads operands
- Enables serial shifting
- Monitors counter completion
- Generates Done signal

---

## Shift Register (`shift_register`)

Two parameterized shift registers are used.

### Shift Register A

- Stores Operand A
- Receives generated sum bits
- Produces the final sum

### Shift Register B

- Stores Operand B
- Supplies serial input to the Full Adder
- Shifts right every clock cycle

---

## Full Adder (`full_adder`)

Performs single-bit binary addition.

### Inputs

- Operand A
- Operand B
- Carry In

### Outputs

- Sum Bit
- Carry Out

---

## Carry Register (`d_ff`)

Stores the carry generated by the Full Adder.

The stored carry becomes the Carry-In for the next clock cycle.

---

## Counter (`counter`)

Counts the number of processed bits.

After all bits are processed, the **count_done** signal is generated, allowing the FSM to enter the DONE state.

---

## Top Module (`serial_adder_with_fsm_top_module`)

Integrates all submodules into a complete parameterized serial binary adder.

### Outputs

- Sum
- Carry Final
- Done

---

# Working Principle

1. Reset initializes all registers.
2. FSM enters the IDLE state.
3. A Start pulse begins the addition process.
4. Operands are loaded into the shift registers.
5. The Full Adder performs one-bit addition during every clock cycle.
6. The generated carry is stored in the D Flip-Flop.
7. Shift Register A stores the generated sum bits.
8. Shift Register B shifts after every clock cycle.
9. The Counter counts processed bits.
10. After all bits are processed, the FSM enters the DONE state.
11. The final Sum and Carry outputs become available.

# FSM State Flow

```text
               +-------+
               | IDLE  |
               +-------+
                   |
                Start
                   |
                   V
               +-------+
               | LOAD  |
               +-------+
                   |
                   V
               +-------+
               | ADD   |
               +-------+
                   |
             count_done
                   |
                   V
               +-------+
               | DONE  |
               +-------+
                   |
                   V
                 IDLE
```
